# Example data

`europe.csv` is the normalized Europe load dataset used by the package's
historical demonstration notebook. It was derived from ENTSO-E data distributed
through the Open Power System Data time-series package. The paper and the
[`leave-one-out_maximum-log-likelihood`](https://github.com/kabolat/leave-one-out_maximum-log-likelihood)
repository describe the source, country selection, date range, and preprocessing.

`toy_data.csv` supports the historical conditional-VAE demonstration. Its
generation procedure was not preserved in this repository, so it should be
treated as example input rather than a reproducible benchmark.

These files are retained for continuity with the original notebooks. Confirm
the upstream data terms before redistributing derived datasets.
